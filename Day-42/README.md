**Graph Adjacency List**

Graph Adjacency List is a way to represent a graph where each node keeps a list of the nodes directly connected to it.

**Simple Definition**

An adjacency list is a data structure used to store a graph. For every vertex (node), we store a list of its neighboring vertices.

**Example**

If we have a graph:

**A** connected to B and C

**B** connected to A and D

**C** connected to A

**D** connected to B
